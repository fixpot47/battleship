# Морской бой

Статический сайт для игры в морской бой вдвоём. Сайт публикуется через GitHub Pages, а онлайн-комнаты используют Supabase Realtime.

## Правила

- Поле 10×10.
- Флот: один корабль на 4 клетки, два на 3, три на 2 и четыре на 1 клетку.
- Корабли прямые. Поворот — клавиша **R** или кнопка **«Повернуть»**.
- Корабли могут касаться углами, но не боковыми сторонами.
- Игрок, попавший в корабль, стреляет ещё раз.
- Победа: **«Вы победили!»**; поражение: **«Вы проиграли...»**.

## Публикация

1. Открой репозиторий **Settings → Pages**.
2. В разделе **Build and deployment** выбери **GitHub Actions**.
3. После каждого изменения в `main` сайт будет публиковаться автоматически.

## Онлайн-комнаты

Чтобы создавать комнаты и играть с другого устройства, нужен Supabase-проект с включённым Realtime. В `config.js` укажи адрес проекта и его **publishable key**:

```js
window.BATTLESHIP_CONFIG = {
  url: "https://YOUR_PROJECT.supabase.co",
  publishableKey: "YOUR_SUPABASE_PUBLISHABLE_KEY"
};
```

Publishable key предназначен для браузерных приложений. **Никогда не вставляй сюда secret key или service_role key.** Не добавляй в репозиторий секретные ключи.

Схема базы данных для текущей версии не нужна: сообщения комнаты проходят через Supabase Realtime Broadcast. Если создатель комнаты закроет страницу, текущая партия завершится.
