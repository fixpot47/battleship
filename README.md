# Морской бой

Сайт для игры в морской бой вдвоём. Файлы публикуются через GitHub Pages, игровые комнаты работают через Supabase Realtime.

## Как играть

1. Первый игрок нажимает **«Создать игру»** и отправляет другу код комнаты.
2. Второй игрок нажимает **«Присоединиться к игре»** и вводит код.
3. Оба расставляют флот: 1 корабль на 4 клетки, 2 на 3, 3 на 2 и 4 на 1.
4. Корабли прямые. Повернуть их можно клавишей **R** или кнопкой **«Повернуть»**.
5. Корабли могут касаться углами, но не боками. Попадание даёт ещё один выстрел.

При победе появится зелёное **«Вы победили!»**, при поражении — красное **«Вы проиграли...»**.

## Публикация на GitHub Pages

Открой репозиторий **Settings → Pages** и в разделе **Build and deployment** выбери **GitHub Actions**. После этого workflow автоматически обновляет сайт при изменениях в ветке `main`.

## Онлайн-сервис

Проект подключён к отдельному Supabase-проекту `battleship` в регионе Frankfurt. Для комнат используются Supabase Realtime Broadcast; таблицы базы данных не нужны. `config.js` содержит только публичный publishable key, предназначенный для браузерных приложений. Секретные ключи в сайт не добавлять.

Если создатель комнаты закрывает страницу, текущая партия заканчивается.
